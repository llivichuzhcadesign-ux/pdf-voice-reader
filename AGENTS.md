# Orbit

Tagline: eyes-free.

Interface phrase: Read, Pause, Mark.

Orbit is a Chrome extension for reading PDFs aloud.

## Project Rules

- Keep the app PDF-only.
- Do not add TXT support.
- Do not add AI voice, ElevenLabs, OpenAI TTS, or API-key menus.
- Use only built-in Mac/Chrome/browser voices.
- Keep the UI black background with white text.
- Keep the interface clean, minimal, and app-like.
- Main controls should be only Read, Pause/Resume, and Mark.
- Mark creates a red bookmark/resume point.
- Preserve saved PDF library.
- Preserve online PDF link support.
- Preserve Google PDF opening.
- Preserve PDF invert.
- Preserve reading progress and highlighting.
- Avoid long descriptions inside the app UI.
- Before changing major logic, explain the plan first.
